# Навигатор по Пушкинскому музею

React SPA для навигации посетителя по залам ГМИИ им. А. С. Пушкина с геймификацией:
чекпойнт-коды, маршруты-квесты, викторина, XP, бейджи и уровни.

## Технологии

- **Vite 5** — сборка и dev-сервер
- **React 18** — UI
- **React Router 6** — HashRouter (работает на любом статичном хостинге без серверной настройки)
- **localStorage** — сохранение прогресса между сессиями

## Скрипты

```bash
npm run dev       # dev-сервер на порту 5173
npm run build     # продакшн-сборка → dist/
npm run preview   # локальный просмотр собранного
```

## Геймификация

- **XP**: зал +20, первый зал +25 бонус, викторина +15, шаг маршрута +10, финиш маршрута +60
- **7 уровней**: Зритель → Посетитель → Любознательный → Знаток этажа → Хранитель маршрутов → Собиратель залов → Пушкинист
- **14 бейджей**: первый шаг, 5 залов, половина музея, весь музей, хозяин этажа, первый маршрут, без промахов и т.д. (+30 XP за каждый)
- **Прогресс сохраняется** в localStorage — данные не теряются между визитами

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Сделайте `git init`, `git add .`, `git commit -m "Initial"`.
3. Добавьте remote: `git remote add origin https://github.com/USERNAME/REPO.git`, `git push -u origin main`.
4. В репозитории: **Settings → Pages → Branch: main, Folder: / (root)**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://USERNAME.github.io/REPO/`.

> `base: './'` в `vite.config.js` делает сборку универсальной — работает и в подпапке,
> и в корне. Не требует изменения конфига при смене имени репозитория.
